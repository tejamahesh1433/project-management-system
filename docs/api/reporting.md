# Reporting API

Phase 10 adds generated operational reports with persisted snapshots and CSV/JSON exports.

## Report Types

- `PROJECT`
- `SPRINT`
- `TEAM`
- `WORKSPACE`

## Generate Report

`POST /api/v1/reports/generate`

```json
{
  "type": "PROJECT",
  "projectId": "uuid"
}
```

Required target fields:

- `PROJECT`: `projectId`
- `SPRINT`: `sprintId`
- `TEAM`: `projectId`
- `WORKSPACE`: `workspaceId`

Response:

```json
{
  "id": "uuid",
  "type": "PROJECT",
  "title": "Website Project Report",
  "workspaceId": "uuid",
  "projectId": "uuid",
  "sprintId": null,
  "generatedById": "uuid",
  "generatedAt": "2026-06-07T12:00:00Z",
  "metrics": {
    "totalTasks": 12,
    "completedTasks": 8,
    "openTasks": 4,
    "members": 5,
    "completionPercentage": 66.67
  }
}
```

## List Reports

`GET /api/v1/reports`

Returns reports generated by the authenticated user, newest first.

## Get Report

`GET /api/v1/reports/{id}`

Returns one generated report and its stored metrics.

## Export JSON

`GET /api/v1/reports/{id}/export/json`

Returns the latest persisted snapshot metrics as JSON.

## Export CSV

`GET /api/v1/reports/{id}/export/csv`

Returns the latest persisted snapshot metrics as a single-row CSV.

## Metrics

Project report:

- `totalTasks`
- `completedTasks`
- `openTasks`
- `members`
- `completionPercentage`

Sprint report:

- `totalTasks`
- `completedTasks`
- `remainingTasks`
- `storyPointsCompleted`
- `storyPointsRemaining`

Team report:

- `assignedTasks`
- `completedTasks`
- `openTasks`
- `averageCompletionTimeHours`

Workspace report:

- `projects`
- `tasks`
- `documents`
- `files`
- `members`
- `activityCount`

## Events

- `ReportGeneratedEvent`
- `ReportExportedEvent`

## Scope Exclusions

Phase 10 does not include analytics, charts, AI insights, or forecasting.
